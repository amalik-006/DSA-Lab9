# DSA Lab 9

This repository contains the implementations of three Data Structures and Algorithms lab tasks using C++.

## Tasks

### Task 1: BST Range Query and Successor/Predecessor Finder
- Construct a Binary Search Tree using recursive insertion
- Find the inorder predecessor and successor of a given key
- Perform recursive and iterative range queries
- Count comparisons during range queries

### Task 2: Word Frequency Indexing using BST
- Process a paragraph and count word frequencies
- Store unique words and their frequencies in a Binary Search Tree
- Display words alphabetically
- Sort words by descending frequency
- Identify the most frequent word(s)

### Task 3: Weighted M-ary Tree – Galaxy Representation
- Represent a galaxy using a weighted M-ary tree
- Store star system information and travel costs
- Check whether the tree is balanced
- Count the leaf nodes
